# v0.7.3 - Delegated authentication scope fix

## Highlights

- Requests the Graph scopes from the original authentication context during delegated sign-in
- Preserves the requested scopes when authentication falls back to the in-memory credential
- Adds regression coverage for delegated scope propagation

## Upgrade notes

- No new permissions are required. Existing `TenantId`/`ClientId` configuration and consent continue to apply.
- Users may need to sign in again if the requested Graph scopes have changed.
