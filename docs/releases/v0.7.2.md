# v0.7.2 - Delegated token-cache restoration

## Highlights

- Restores delegated authentication across process restarts when persistent
  token caching is available
- Persists the non-secret authentication record needed to select the cached
  account on the next startup
- Falls back cleanly when the platform token cache or authentication record
  cannot be read
- Added regression coverage for cache restoration, paths and failure cases

## Upgrade notes

- No new permissions are required. Existing delegated permissions and
  `TenantId`/`ClientId` configuration continue to apply.
