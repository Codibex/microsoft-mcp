# v0.11.0 - New servers: SharePoint, To Do, Planner

## Highlights

- New SharePoint server (10 tools, explicit driveId, read/create/move, no delete) with Teams channel files bridge
- New To Do server (4 tools, add/complete, no delete) and Planner server (4 tools, read-only)
- Teams server is now read-only (message sends removed)
- OneDrive path-based up/download with resumable sessions (large files bypass model context)
- Fixes Outlook attachment content fetch without `$select` and setup/doctor/cli audit findings

## Upgrade notes

- Existing `TenantId`/`ClientId` configuration keeps working.
- When using the new servers, add their delegated scopes from `docs/setup.en.md §2` in Entra and consent again (SharePoint/Planner need a work account).
- Teams write tools were removed; existing read-only usage is unaffected.
- Existing policy files remain compatible with the current policy format.
