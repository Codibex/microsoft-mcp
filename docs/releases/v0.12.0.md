# v0.12.0 - Teams search & chat members, .NET 11

## Highlights

- Adds `teams_search_messages` for read-only full-text search across Teams chats and channel messages via Microsoft Search (`POST /v1.0/search/query`, work/school accounts)
- Adds `teams_list_chat_members` to list member display names, emails, user IDs, and roles for a specific chat (including group chats beyond the 25-member `$expand` cap)
- Improves `teams_list_chats` with `@odata.nextLink` paging (up to 500 scanned chats), newest-activity-first sorting, and inline member names via `$expand=members` (with HTTP 400 fallback)
- Upgrades the solution from .NET 10 / C# 14 to .NET 11 / C# 15 and `Microsoft.Extensions.*` 11.0.0
- Updates README server status for Outlook, Calendar, and Teams to live-verified for personal and work/school accounts

## Upgrade notes

- Self-contained release binaries require no .NET runtime and continue to work with existing `TenantId`/`ClientId` configuration and policy files.
- Building from source now requires the .NET 11 SDK (`11.0.100` or later).
- No new Entra permissions are required: `teams_list_chat_members` uses `Chat.ReadBasic` and `teams_search_messages` uses the existing `Chat.Read` / `ChannelMessage.Read.All` scopes.

Full changelog: https://github.com/Codibex/microsoft-mcp/compare/v0.11.0...v0.12.0
