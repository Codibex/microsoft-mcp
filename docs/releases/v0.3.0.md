# v0.3.0 – Read attachments

## Highlights

- New tool `read_attachment` (17 total): text files decoded (truncated at
  20000 chars), binaries as base64, nested messages and OneDrive links
  reported instead of downloaded
- New error code `attachment-too-large` (default limit 768 KB, raisable to
  2097152 bytes) so large files never blow up the agent context

## Upgrade notes

No config changes. Drop-in replacement for the v0.2.0 binary.

Full changelog: https://github.com/Codibex/microsoft-mcp/compare/v0.2.0...v0.3.0
