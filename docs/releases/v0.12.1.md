# v0.12.1 - Teams chat listing server-side ordering, filtering, and paging

## Highlights

- Fixes `teams_list_chats` missing recently active, older 1:1 chats in large mailboxes (>500 chats) by using Graph's server-side `$orderby=lastMessagePreview/createdDateTime desc` with `$expand=members,lastMessagePreview` (`#66`, `#67`)
- Adds optional `skip`, `chatType` (`oneOnOne`, `group`, `meeting`), and `orderBy` (`lastMessage` default, or `lastUpdated`) parameters to `teams_list_chats` so callers can page, filter, and control sorting directly
- Prefers `lastMessagePreview.createdDateTime` over stale `chat.lastUpdatedDateTime` for `LastUpdated` and preserves newest-message ordering in the HTTP 400 client-side fallback

## Upgrade notes

- Drop-in patch release over `v0.12.0`: no breaking changes to tool return shapes, existing defaults, configuration, or Entra permissions.
- Self-contained release binaries require no .NET runtime.

Full changelog: https://github.com/Codibex/microsoft-mcp/compare/v0.12.0...v0.12.1
