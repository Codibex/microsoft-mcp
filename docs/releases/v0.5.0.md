# v0.5.0 – Calendar host (read-only)

## Highlights

- New MCP server `microsoft-mcp-calendar` (4 tools, strictly read-only):
  `list_calendars`, `list_events` (time-window view, default now + 7 days),
  `search_events`, `read_event` (attendees, recurrence summary, body,
  online-meeting link)
- New error codes `calendar-not-found` / `event-not-found`; 404 wording is
  now resource-aware across all hosts
- Docs split per MCP (`docs/outlook.md`, `docs/onedrive.md`,
  `docs/calendar.md`); release assets ship all three servers

## Upgrade notes

- Add the delegated permission `Calendars.Read` to the Entra app
  (consent again if needed). Same `TenantId`/`ClientId` config.
