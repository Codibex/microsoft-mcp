# v0.2.0 – Full triage scope, actionable errors, release assets

## Highlights

- Full Outlook scope – 16 tools: reply/forward drafts (`create_reply_draft`,
  `create_forward_draft`), draft updates (`update_draft`), `create_folder`,
  `list_attachments`, `list_categories`, `set_importance`
- **Actionable errors (MCP best practice):** failures return `isError`
  results with stable `[code]` + `Next:` recovery hints instead of generic
  SDK text; full detail stays in the server log. Covers Graph codes
  (`ErrorItemNotFound`, throttling, consent) and `AADSTS` auth codes
- Docs split into delegated/app-only recipes; README fully in English
- First release with ready-made binaries (linux-x64, win-x64, osx-arm64)
  plus SHA256 checksums

## Upgrade notes

- Env vars changed: `GRAPH__*` → `Graph__*` (the old prefix never bound
  to the `Graph:` section). Update `mcp.json`/shell env accordingly.
- Config is now resolved from the binary location (working directory no
  longer matters); startup fails fast with hints and logs the active mode.
- Personal accounts: set `TenantId` to `common`, app audience org +
  personal, token version 2 (see troubleshooting in `docs/outlook.md`).
