# v0.7.1 - Authentication and setup fixes

## Highlights

- More reliable delegated token-cache fallback on headless Linux hosts
- Corrected authority handling for personal-only Microsoft accounts
- Clearer setup and doctor guidance for account type, domains, clients and
  valid server/authentication combinations
- Added regression coverage for token acquisition, setup validation and
  resource-aware Graph errors

## Upgrade notes

- No new permissions are required. Existing delegated permissions and
  `TenantId`/`ClientId` configuration continue to apply.
