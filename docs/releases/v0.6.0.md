# v0.6.0 – Teams host (read-only)

## Highlights

- New MCP server `microsoft-mcp-teams` (9 tools, strictly read-only):
  `list_teams`, `list_channels`, `list_channel_messages`,
  `list_message_replies`, `read_channel_message`, `list_chats`,
  `list_chat_messages`, `list_chat_replies`, `read_chat_message`
- Message previews as plain text (HTML stripped); full messages with
  reactions and mentions; thread support for channels and chats
- New error codes `team-not-found`, `channel-not-found`, `chat-not-found`,
  `channel-message-not-found`; 404 wording is resource-aware across all hosts
- Release assets ship all four servers as self-contained binaries

## Upgrade notes

- Add the delegated permissions `Team.ReadBasic.All`,
  `ChannelMessage.Read.All`, `Chat.ReadBasic` and `Chat.Read` to the
  Entra app (consent again if needed). Same `TenantId`/`ClientId` config.
- This host supports delegated auth only (app-only rejected at startup
  with a hint). No send/create/update/delete exists by design.
