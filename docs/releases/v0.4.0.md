# v0.4.0 – OneDrive host

## Highlights

- New MCP server `microsoft-mcp-onedrive` (9 tools): `get_drive`,
  `list_drives`, `get_item`, `list_children`, `search_files`,
  `download_file`, `create_folder`, `upload_file`, `move_item`
- Read, create and move only – **no delete**, by design
- Items addressed by `"root"`, id or `/path`; shared auth/error handling
  from `Common`, new `item-not-found` code
- New guide: `docs/onedrive.md`; release assets now ship both servers

## Upgrade notes

- Add the delegated permissions `Files.Read` + `Files.ReadWrite` to the
  Entra app (consent again if needed). Same `TenantId`/`ClientId` config.
- This host supports delegated auth only (app-only rejected at startup
  with a hint).
- `upload_file` is a simple upload capped at 4194304 bytes.

Full changelog: https://github.com/Codibex/microsoft-mcp/compare/v0.3.0...v0.4.0
