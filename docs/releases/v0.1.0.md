# v0.1.0 – Initial Outlook MCP

First working cut: a local MCP server (Stdio) that puts an email-triage
layer over the Microsoft Graph Outlook API.

## Highlights

- 9 triage tools: `search_emails`, `read_email`, `list_folders`,
  `move_email`, `archive_email`, `delete_email` (trash only),
  `create_draft` (no send), `set_categories`, `mark_read`
- Delegated (browser/device-code) and app-only auth, token cache,
  config via `appsettings.json`, user-secrets or env vars
- Central build: `Directory.Build.props` + central package management,
  .NET 10 / C# 14, xUnit suite with an in-memory fake

## Upgrade notes

Follow `docs/outlook.md` (recipes A/B) to register the Entra app and
configure `Graph:TenantId` + `Graph:ClientId`. No binaries attached to
this release – build from source (`dotnet build MicrosoftMcp.slnx`).

Full changelog: initial release, no predecessor.
